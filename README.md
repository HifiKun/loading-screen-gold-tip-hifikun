One sharp, funny loading-screen tip for stressed developers and AI coding agents, in 200 characters or fewer. The program writes the tip to `/output/entry.txt`.

The tip puts the developer and their AI agent side by side in front of the same loading bar — both waiting, both wondering which one of them wrote the bug.

## Run it

```sh
node main.ts
```

It writes one line to `/output/entry.txt` (or to `$OUTPUT_PATH` when set, for local testing). The output is deterministic: every run writes the same line.
